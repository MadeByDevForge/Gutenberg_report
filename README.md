# CSCU9M3 — Gutenberg Literary Analysis

## Overview

This repository contains my CSCU9M3 coursework for Autumn 2026.

The project uses Python and Jupyter Notebook to analyse a collection of 20 books from Project Gutenberg, focusing on differences in authors' writing styles and storytelling techniques.

## Areas of Investigation

- Sentence length and writing style
- Dialogue versus narration
- Vocabulary and authorial patterns
- Character prominence

The project will initially explore all 20 books before selecting specific works for further analysis.

## Tools

- Python
- Jupyter Notebook
- Git and GitHub Desktop

## Progress

This project is currently in development, beginning with data loading, validation and cleaning before moving on to exploratory and descriptive analysis.

## Dataset

Source: [Project Gutenberg](https://www.gutenberg.org/)
